# Infrastructure environments

Reserved for per-environment composition of `infra/modules` (for example
`dev`, `staging`, `production`, and customer-cloud or private deployments).

**Status:** intentionally empty. No shared or production environment is
defined, provisioned or validated in Milestone 0. SaaS, customer-cloud,
private-data-centre and air-gapped deployment remain product requirements
that have not been proven (see the consolidated brief §15 and §21).
